## UCI Sentiment Labelled Sentences

The external sentiment benchmark stored under `data/external/uci_sentiment_labelled_sentences/` is the Amazon subset of **Sentiment Labelled Sentences**, UCI Machine Learning Repository, DOI `10.24432/C57604`.

UCI distributes this dataset under **Creative Commons Attribution 4.0 International (CC BY 4.0)**. The repository preserves the dataset name, source member, source URL, row count, SHA-256 checksum, task scope, and license in the adjacent `manifest.json`.

Attribution: Dimitrios Kotzias (2015), *Sentiment Labelled Sentences*, UCI Machine Learning Repository, DOI `10.24432/C57604`.

The synthetic datasets in `data/input/` are generated by this repository and are not derived from the UCI examples.
